# useful-indeed

A growing shelf of small, free web tools that run in your browser.

**Live:** https://useful-indeed.com

useful-indeed is a small collection of free web tools, each living on its own subdomain with its own design. Every tool does one job — PDFs, savings estimates, loan costs, random memes, raffles, a block-stacking game, choir lineups, code formatting, test data and focus timing — and does it inside your browser.

## Privacy

Everything runs in your browser. The main page does not store anything about you. Your browser may cache the page and its fonts so it loads faster next time.
